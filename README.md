# Data Structures & Algorithms 🧠

A curated collection of **LeetCode problem solutions written in Java**, organized by data structure and algorithmic pattern. This repo serves as a personal reference and practice log for mastering DSA concepts commonly tested in technical interviews.

## 📖 About

This repository contains solutions to LeetCode problems, categorized by topic for easy navigation and review. Each file is named using the convention:

```
<Topic>-<Difficulty>-<Problem Number>. <Problem Title>.java
```

For example: `Array-Med-198. House Robber.java` indicates a **Medium**-difficulty **Array** problem — LeetCode #198, "House Robber".

## 🚀 Getting Started

### Prerequisites

- [Java JDK](https://www.oracle.com/java/technologies/downloads/) (8 or higher recommended)
- A Java IDE or editor (IntelliJ IDEA, Eclipse, VS Code, etc.)

### Running a Solution

Each `.java` file is self-contained and can be compiled and run individually:

```bash
javac "Arrays/Array-Easy-1480 Running Sum of 1d Array.java"
java -cp Arrays "Array-Easy-1480 Running Sum of 1d Array"
```

> Note: Class names inside each file must match the filename (minus the `.java` extension) for standalone compilation. Adjust the `public class` name if needed, or strip the `public` modifier when running quickly via an IDE scratch file.
